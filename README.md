## 🚀 Deployment Instructions for GitHub

```bash
git init
git add .
git commit -m "Initial commit of Senior Android Engineer Portfolio"
git branch -M main
git remote add origin https://github.com/fahaddev02/MyPortfolio.git
git push -u origin main
```

To enable **GitHub Pages**:
1. Go to your repository settings on GitHub (`https://github.com/fahaddev02/MyPortfolio/settings/pages`).
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
4. Your website will be live at: `https://fahaddev02.github.io/MyPortfolio/`
